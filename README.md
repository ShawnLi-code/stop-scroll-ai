# 别刷了 AI (StopScroll AI) 🛡️

> 一款基于 Android 无障碍服务与大语言模型 (LLM) 的深度自律守护应用。

---

### ✨ 核心机制

1. **瞬时应用拦截**：启动小红书、抖音、B站、快手、微博等目标应用瞬间拦截，切回桌面并弹出意图询问卡片。
2. **意图与倒计时约束**：用户必须回答“这次打开要做什么？”以及“计划使用多少分钟？”，方可进入应用。
3. **AI 动态屏幕护航**：在设定的专注时间内，无障碍服务低开销提取屏幕关键文本，调用 DeepSeek/大模型 实时分析当前浏览内容是否偏离了目标。
4. **防沉迷强制跳出**：如果用户声称看做饭教程，却连续采样检测到搞笑/热舞/八卦短视频，或倒计时归零，AI 强制执行全局返回回到桌面，并给予提醒！

---

### 📱 OPPO Find X9 (ColorOS) 安装与配置指南

1. **安装 APK**；
2. **开启“允许受限制的设置”**：长按桌面图标 -> 应用信息 -> 右上角三个点 -> 点击“允许受限制的设置”；
3. **开启无障碍服务**：设置 -> 系统设置 -> 无障碍 -> 已下载的应用 -> 开启【别刷了 AI】；
4. **授予悬浮窗与后台运行权限**：在主界面点击对应按钮一键跳转授权；
5. **填入 API Key**：输入你的 DeepSeek API Key，点击“测试连接”并保存。
